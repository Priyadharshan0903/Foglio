# Foglio icon explorations

Four exploratory directions in `comparison.png`. These do not replace the app icon.

1. **Folded F** — An F silhouette with an amber fold. Recommended for a distinctive identity that still suggests paper.
2. **Layered pages** — Overlapping ivory pages on charcoal, with an amber bookmark. The most tactile option; it emphasizes writing.
3. **Studio monogram** — A rounded F and amber dot on charcoal. The simplest, strongest silhouette at small sizes.
4. **Refined margin** — The existing margin mark with warmer paper and more deliberate spacing. Offers continuity with the current identity.

Each appears at a large preview size and at 32 pixels. These are code-drawn vector concepts rasterized for comparison, not final production assets. After selection, refine optical spacing and export all required macOS icon sizes.

Regenerate from the repository root:

```sh
swift design/icon-concepts/preview.swift
```
