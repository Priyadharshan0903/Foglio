You choose the access. Write tools require Allow changes. Calendar URLs and .ics files support reading and meeting follow-ups; event editing needs a writable macOS calendar and existing Calendar permission.

Your edits stay in view. Revision checks protect newer changes, and open task drafts are protected from agent edits. No delete, arbitrary-file, or shell-execution tools are exposed.

A local connection. Foglio uses stdio and a private Unix socket, without an HTTP port or hosted bridge. Your agent’s model provider may receive the content the agent reads, according to its own configuration.

BEFORE YOU SETTLE IN.

A few details.

Which Macs can run Foglio?+

This download is for Apple silicon Macs running macOS 14 or later. An Intel build is not included in this preview.

Is this the finished release?+

This is an early preview, version 0.5.0, for trying Foglio and exploring the workflow. It is locally signed and is not yet notarized, so macOS may display a security warning when opening it.

Where do my notes and tasks go?+

They are stored locally on your Mac. Notes are Markdown files, and you can reveal the notes folder or export your work from Settings. Calendar access depends on the source you select.

Can my agents use Foglio?+

Yes. The app includes a local MCP stdio server for Codex, Claude Code, and Claude Desktop, with 26 tools for notes, tasks, statuses, calendars, and meeting follow-ups. Enable access in Settings → Agent connections, copy your setup, and keep Foglio open. Reading is the default; changes need your permission. Explore connector support.

How do I install the app?+

Download the DMG, open it, and drag Foglio to the Applications shortcut inside. This preview’s shortcut points to your personal Applications folder.
